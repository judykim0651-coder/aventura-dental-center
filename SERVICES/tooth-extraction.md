## Detailed Description

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│  ## What Is a Tooth Extraction?                                            │
│                                                                             │
│  A tooth extraction is the removal of a tooth from its socket in the bone.  │
│  While preserving natural teeth is always the priority, extractions become  │
│  necessary when a tooth is too damaged to repair, severely infected, or     │
│  causing crowding that affects bite alignment. Wisdom teeth, baby teeth     │
│  that won't fall out, and teeth compromised by advanced periodontal disease │
│  are also common candidates for extraction.                                 │
│                                                                             │
│  We perform both simple extractions (for visible teeth) and surgical        │
│  extractions (for impacted or broken teeth) under local anesthesia to       │
│  keep you comfortable throughout. After the procedure, we provide clear     │
│  aftercare instructions and discuss tooth replacement options — such as     │
│  implants, bridges, or dentures — so you can restore function and protect   │
│  your long-term oral health.                                                │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## How to Care

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│  ## How to Care After a Tooth Extraction                                   │
│                                                                             │
│  • **Bite** on gauze for 30–45 minutes to allow a blood clot to form        │
│  • **Avoid** rinsing, spitting, or using straws for 24 hours                 │
│  • **Apply** an ice pack to the outside of your cheek for 20-minute         │
│    intervals to reduce swelling                                             │
│  • **Take** prescribed or over-the-counter pain relievers as directed       │
│  • **Eat** soft foods for the first 24–48 hours — avoid hot, spicy, or      │
│    crunchy items                                                             │
│  • **Do not** smoke or use tobacco — it delays healing and can cause        │
│    dry socket                                                               │
│  • **Gently** rinse with warm salt water after 24 hours to keep the area   │
│    clean                                                                     │
│  • **Call us** if bleeding persists, pain worsens, or you have signs of     │
│    infection (fever, swelling after 48 hours)                                │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
