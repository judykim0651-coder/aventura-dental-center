│                                                                             │

## How to Care

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│  ## How to Handle a Dental Emergency                                       │
│                                                                             │
│  ### Knocked-Out Tooth                                                     │
│  • Pick up the tooth by the crown (not the root), rinse gently              │
│  • Try to place it back in the socket, or keep it in milk or saliva         │
│  • See us immediately — time is critical                                    │
│                                                                             │
│  ### Severe Toothache                                                       │
│  • Rinse with warm water, floss gently to remove trapped debris             │
│  • Apply a cold compress to the outside of the cheek                        │
│  • Take over-the-counter pain reliever as directed                          │
│  • Do NOT place aspirin directly on the gum                                 │
│                                                                             │
│  ### Broken or Chipped Tooth                                               │
│  • Rinse mouth with warm water, save any broken pieces if possible          │
│  • Apply gauze if there's bleeding; cold compress for swelling              │
│  • Cover sharp edges with dental wax or sugarless gum temporarily           │
│                                                                             │
│  ### Lost Filling or Crown                                                  │
│  • Keep the crown if you have it — temporary dental cement can hold it      │
│  • Avoid chewing on that side until it can be re-cemented                   │
│                                                                             │
│  **If you're unsure whether it's an emergency, call us at (305) 933-2501.**  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
