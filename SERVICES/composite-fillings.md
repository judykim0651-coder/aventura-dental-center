## Detailed Description

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│  ## What Are Composite Fillings?                                           │
│                                                                             │
│  Composite fillings are tooth-colored restorations used to repair cavities  │
│  caused by decay. Made from a durable resin-based material that can be      │
│  precisely color-matched to your natural teeth, composite fillings offer a  │
│  cosmetic alternative to traditional silver amalgam fillings. The material  │
│  bonds directly to the tooth structure, which allows us to preserve more    │
│  healthy tooth compared to the more invasive preparation needed for         │
│  amalgam.                                                                   │
│                                                                             │
│  Composite fillings are ideal for small to medium-sized cavities in both    │
│  front and back teeth. They can also be used to repair chipped, cracked,    │
│  or worn teeth. In addition to their aesthetic advantage, composite          │
│  materials strengthen the tooth by bonding to the enamel, creating a        │
│  tight seal that minimizes sensitivity and helps prevent future decay at   │
│  the restoration margin.                                                    │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## What to Expect

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│  ## What to Expect — Composite Filling Procedure                           │
│                                                                             │
│  Step 1 ────►  Examination and diagnosis — the tooth is evaluated and       │
│               X-rays confirm the extent of decay                            │
│                                                                             │
│  Step 2 ────►  Local anesthesia administered to numb the area if needed     │
│                                                                             │
│  Step 3 ────►  Decay removal — the affected portion of the tooth is         │
│               gently removed, leaving healthy structure intact               │
│                                                                             │
│  Step 4 ────►  Tooth preparation and etching — the surface is conditioned   │
│               to help the composite bond securely                           │
│                                                                             │
│  Step 5 ────►  Composite applied in layers — each layer is shaped and       │
│               hardened with a curing light                                  │
│                                                                             │
│  Step 6 ────►  Final shaping and polishing — filling is contoured, shaped,  │
│               and polished to match the natural tooth anatomy                │
│                                                                             │
```

## How to Care

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│  ## How to Care for Composite Fillings                                     │
│                                                                             │
│  • **Brush** twice daily with fluoride toothpaste — gentle around the       │
│    filled area                                                              │
│  • **Floss** daily to prevent decay at the gum line near the filling        │
│  • **Avoid** chewing ice, hard candy, or biting nails — can chip the        │
│    composite                                                                │
│  • **Limit** staining foods and drinks (coffee, tea, red wine) in the       │
│    first 48 hours                                                           │
│  • **Rinse** with fluoridated mouthwash to protect the surrounding enamel   │
│  • **Visit** your dentist regularly so we can check the integrity of your   │
│    fillings                                                                 │
│  • **Report** any roughness, chipping, or sensitivity around the filling    │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
