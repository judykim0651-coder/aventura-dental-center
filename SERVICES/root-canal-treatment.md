## Detailed Description

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│  ## What Is Root Canal Treatment?                                          │
│                                                                             │
│  Root canal treatment (endodontic therapy) is a procedure designed to save  │
│  a tooth that has become infected or severely decayed. The infection        │
│  originates in the dental pulp — the soft tissue inside the tooth — and can │
│  cause intense pain, sensitivity, and swelling if left untreated.           │
│                                                                             │
│  During the procedure, the infected pulp is carefully removed, the interior │
│  of the tooth is cleaned and disinfected, and the space is filled and       │
│  sealed. The tooth is then protected with a crown or filling. Root canal    │
│  treatment relieves pain and allows you to keep your natural tooth —        │
│  avoiding the need for extraction and replacement.                          │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## What to Expect

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│  ## What to Expect — Root Canal Procedure                                  │
│                                                                             │
│  Step 1 ────►  Examination and X-rays to assess the infection and tooth     │
│               structure                                                     │
│                                                                             │
│  Step 2 ────►  Local anesthesia administered to ensure complete comfort     │
│               during the procedure                                          │
│                                                                             │
│  Step 3 ────►  Small access opening made in the tooth; infected pulp         │
│               removed using specialized instruments                          │
│                                                                             │
│  Step 4 ────►  Canals cleaned, disinfected, and shaped — then filled with    │
│               a biocompatible material (gutta-percha)                       │
│                                                                             │
│  Step 5 ────►  Temporary or permanent filling placed; crown recommended     │
│               later to protect the restored tooth                            │
│                                                                             │
│  Step 6 ────►  Follow-up to check healing and place final restoration       │
│                                                                             │
```

## How to Care

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│  ## How to Care After a Root Canal                                        │
│                                                                             │
│  • **Wait** for numbness to wear off before eating to avoid biting your     │
│    cheek or tongue                                                         │
│  • **Avoid** chewing on the treated tooth until a permanent crown or        │
│    filling is placed                                                        │
│  • **Take** over-the-counter pain relievers as recommended for mild soreness │
│  • **Brush** and floss normally — gentle care around the treated area       │
│  • **Avoid** hard or sticky foods for the first few days                    │
│  • **Follow up** for your permanent restoration — the tooth needs a crown   │
│    to remain functional long-term                                           │
│  • **Report** any persistent pain, swelling, or discomfort to your dentist  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
